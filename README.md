# Controle de Despesas 2026

## Sobre o projeto

Sistema desenvolvido para organizar e acompanhar despesas financeiras de diferentes pessoas.

O objetivo é facilitar o controle dos gastos, permitindo visualizar despesas individuais e um resumo financeiro geral.

## Funcionalidades

- Cadastro de pessoas.
- Cadastro de salário e alimentação.
- Registro de despesas.
- Separação de despesas por pessoa.
- Visualização geral dos gastos.
- Cálculo automático do saldo disponível.
- Exclusão de despesas.
- Armazenamento de dados no navegador utilizando JSON e localStorage.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- JSON
- LocalStorage

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.
